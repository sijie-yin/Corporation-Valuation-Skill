# 非上市公司实物期权估值：σ 替代指标分析与 V3 合并改进规格
**接续：V1 验证报告 → V2 修复版 ｜ 分析：麻小 ｜ 2026-09-22**

---

## 一、为什么 σ 对非上市公司失灵

B-S 模型的 σ 经济含义是**标的资产价值的不确定性**。上市公司的操作惯例是"股票年收益波动率"——因为它可观测、连续、含预期。非上市公司没有交易价格序列，σ 直接断源。更隐蔽的问题是：即便借用外部数据，非上市公司的风险结构与上市公司存在系统性差异（流动性、透明度、集中度），单纯"借一个 σ"会同时引入测量偏差与结构偏差。

## 二、候选替代指标分析（按可用性排序）

**候选 1：可比上市公司组合 σ（推荐首选）**
做法：取同行业同规模段 8-15 家上市公司，计算各自 2-3 年日收益年化波动率，取**中位数**（剔除上市首年、重大重组期样本）。
- 优点：保留"市场预期定价风险"的口径，与 B-S 推导假设最兼容；数据可得（行情接口即可算，本工作区已具备管线）
- 缺点：A 股小样本行业（如垂直行业软件）可比性打折；含 A 股自身波动率溢价
- 校准：非上市公司建议在可比 σ 基础上 **上浮 10-20%**（规模与透明度折价方向），并叠加流动性折扣 DLOM 20-30%（对应估值结果直接折减，不动 σ 本身）

**候选 2：自身经营波动率——营收/EBIT 增速标准差（推荐次选/交叉验证）**
做法：取标的 5 年以上营收（或 EBIT）序列，计算同比增速的（几何）标准差，得 σ_经营。
- 关键转换：经营波动 ≠ 资产价值波动。价值波动 ≈ 经营波动 × 经营杠杆放大系数。实务近似：
  - 用 **EBIT 波动率** 时放大已内含利息前利润的敏感性，可直接近似资产回报波动
  - 用 **营收波动率** 时需乘以经营杠杆调整：σ_资产 ≈ σ_营收 ×（1+固定成本占比）
- 优点：来自企业自身数据，无外部可比性偏差；对"报表扎实但无股价"的非上市标的最贴身
- 缺点：历史波动≠前瞻预期；5 年数据对初创公司不可得
- 初创适配：数据不足 5 年时，用可比组合 σ 与自身可得年限波动率加权（年限越短外部权重越高）

**候选 3：Monte Carlo 现金流模拟（机构级，成本高）**
对经营现金流建随机模型（增长与利润率各设分布），模拟数千次得企业价值分布，其标准差/均值即 σ。最严谨但建模成本高，适合大型并购标的，日常估值不经济。

**候选 4：行业经验值/专家打分（兜底）**
评估实务（参考 IVS 及国内资产评估准则对无形资产/期权法的披露要求）允许用行业经验区间 + Delphi 专家调整。软件与信息技术服务业经验区间 σ≈35-50%。仅作无数据时的量级兜底，需在报告中显式披露主观性。

**反面清单（不建议）**：用账面净资产波动（几乎恒定，无信息量）；用单一可比公司 σ（个体噪声大）；把 DLOM 混进 σ 调整（折扣走估值端，σ 只管波动，二者混用会重复惩罚）。

## 三、推荐决策树

```
有同行业可比上市公司？（绝大多数软件企业：有）
 ├─ 有 → 可比组合 σ 中位数，上浮 10-20%，叠加 DLOM 20-30% 于估值端   ← 首选
 └─ 无 → 自身 EBIT/营收波动率 × 经营杠杆转换
          ├─ 数据≥5年 → 直接用，与行业经验区间（35-50%）交叉校验
          └─ 数据<5年 → 与行业经验值加权，披露权重
机构级预算 → Monte Carlo 现金流模拟 σ
```

## 四、与 V3 改进项合并（总规格）

V2 遗留问题（营收现值流不感知毛利率、低毛利集成商被高估、σ 单一假设）+ 本次 σ 非上市适配，合并为 **V3 规格**：

| 模块 | V2 现状 | V3 改进 |
|---|---|---|
| S₀ 标的 | 营收增长年金现值 | **毛利率加权**：S₀ = 营收现值 ×（毛利率/行业基准毛利率，截断 0.6-1.5）；或经常性利润 × 行业乘数（二选一，前者数据更易得） |
| σ 波动率 | 统一 0.40 | **分层适配**：上市公司→个股实际 σ（2 年日收益年化）；非上市→可比组合 σ 中位数 ×（1+10~20%）上浮；数据自足型→EBIT 增速标准差 × 经营杠杆 |
| 流动性 | 无 | 非上市标的估值端 **DLOM 20-30%** 折减（不与 σ 混用） |
| 判定 | 五档估值带 | 保持，另增"非上市参考区间"显示（±DLOM 双口径） |
| 计算器 | V2 页 | 新增"σ 助手"页签：输入可比组合或 5 年财务序列 → 自动算 σ 并回填主模型 |

**验证计划**：V3 落地后用同一批 8 家上市公司回测（其个股 σ 可算，作真值对照可比组合法误差），并选取 2-3 家新三板/一级市场软件公司做非上市链路演示。

---
*本分析为方法论备忘，指标选择最终应以标的数据可得性与估值用途（投资/并购/审计）校准；DLOM 取值参考限制性股票折扣研究常用区间。*
