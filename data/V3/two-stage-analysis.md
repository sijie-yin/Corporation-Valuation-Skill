## 一、公式实现（严格按建议）

- 前三年：逐年实际 g（2023/2024/2025 真实营收增速），逐年折现
- 偏差均值：δ̄ = mean( g_i − ḡ_ind,i )，行业均值 ḡ_ind,i 取 8 家当年横截面均值
- 后五年增长系数：**g_late = ḡ_ind（三年均值） + δ̄**
- S₀ = Σ前三年逐年现值 + Σ后五年按 g_late 复利折现，再乘毛利率权重
- 其余机制同 V3（M 乘数、个股 σ、估值带）

行业年增长均值（2023/2024/2025）：2.9% / −2.6% / 1.6%

## 三、方案有效性的两点证实

**1. 趋势甄别力显著（方案设计意图达成）**
V3 的两处误判被 δ̄ 机制精准修复：
- **浪潮**（V3 误判深度低估）：三年序列 23.1→−26.8→−38.2% 的恶化趋势被偏差均值 −14.6pp 捕获 → g_late=−14% → 正确翻为"高估"
- **中软**（三年连负）→ δ̄=−18.9pp → 深度高估 ✓
- **金山**从"合理区间"上移为"低估"，兑现其持续 15% 增长 ✓
结论：**"偏差均值"确实比"机械取行业均值"更能保留企业个体增长动能信息**——这正是方案要解决的客观性问题。

**2. 增长年金发散被部分抑制，但未根除（诚实交底）**
- 讯飞 S₀ 3838亿 → 3726亿（g_late 13.1% 仍高）；C/市值 4.29 → 3.78，收敛有限
- 东软 6.96 → 6.91，基本未动
- 机理：**对"持续性超越者"，三年偏差均值 δ̄ ≈ 其超额水平本身**（讯飞每年都超行业 12pp+，δ̄=12.5pp），g_late 依然 ≫ r，后五年复利照样发散。方案能平滑"单年尖峰"，不能衰减"结构性超额"。

## 四、建议的收口补丁（V4 最终形态）

在 Jerome 方案上加一个**超额衰减因子 λ**（估值理论中超额增长不可永续，H 型模型通用做法）：

```
g_late = ḡ_ind + λ · δ̄        （λ 建议取 0.5）
```

- 持续超越者：讯飞 g_late = 1.3% + 0.5×12.5pp ≈ 7.6%（仍高于行业，但发散被折半）
- 衰退者：中软 g_late = 1.3% + 0.5×(−18.9pp) ≈ −8.2%（仍显著负增长，趋势信息保留一半）
- λ 的选择可在计算器做成滑杆，敏感性一目了然

**判定**：Jerome 方案在方向甄别上是四版最优（6/8），建议原样采纳为主体机制；λ 衰减作为可选开关补上"量纲收敛"的最后一环。是否落地为 V4 计算器+全量验证，听候指令。
